Extract the user's intent as JSON only.

Supported intents:
- create_task
- list_tasks
- summarize_tasks
- motivational_response
- open_app
- open_website
- play_music
- take_screenshot
- start_study_workspace
- start_workflow
- general_chat

For create_task, include title, description, and priority when available.
Priority must be one of: low, normal, high.
For open_app, include app_name.
For open_website, include url.
For play_music, include query or playlist_url.
For start_study_workspace, include topic and optional app_name.
For start_workflow, include goal. Use start_workflow when the user asks Cherry
to prepare, run, orchestrate, schedule, or execute a multi-step workflow.

Return this shape:
{{"intent":"create_task","title":"study numpy","description":"","priority":"normal"}}

User message:
{user_message}
